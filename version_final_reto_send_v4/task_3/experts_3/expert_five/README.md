# Experto five

Calibrador de horizonte y event sobre riesgo CAPRA-S del portavoz predeclarado.

Entrenamiento: `.venv/bin/python delete_final_versions_task/task_3/experts_3/expert_five/train_expert_five.py` desde la raíz.

Ejecuta el protocolo común de los cinco expertos, incluida CV anidada y ablaciones.
Modelo: `model/expert_five.joblib`. Informe: `../train/artifacts/expert_five_report.json`.
Consulta [el informe comparativo](../README.md) para métricas fuera de muestra, limitaciones y aceptación.
